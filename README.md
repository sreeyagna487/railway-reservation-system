# railway-reservation-system
this project mainly helps the passengers to book trains according to the time or day they want to travel and also helps to check the availability of a train to their desired destinations and class. This railway reservation system makes booking trains much more easier and simple rather than waiting in long queues for buying train tickets. 
## Database Tables

1. STATIONS
2. ROUTES
3. TRAINS
4. PASSENGERS
5. RESERVATIONS
6. TICKETS

## Features

- Station management
- Route management
- Train management
- Passenger management
- Railway reservations
- Ticket management
- Foreign key relationships
- Data validation using constraints
